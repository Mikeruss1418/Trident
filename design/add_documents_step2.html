=== TRISECT ADD DOCUMENTS — STEP 2: ASSIGN CATEGORIES ===

CATEGORY DATA MODEL: - Categories are stored as simple String arrays per document metadata - No separate Category table/DB (keeps it lightweight) - Default categories: Work, Personal, Finance, Documents, Images - Categories are case-insensitive, trimmed on creation - Each document can have 0-3 categories (UX constraint)

BATCH ASSIGNMENT MODE: - "Select All" checkboxes per file row (checkbox replaces the 📝 icon) - "Bulk Assign" opens a popup showing all selected files with a multi-select category tag cloud - Applied category goes to ALL selected files at once - "Rename" opens inline rename for selected file names

PER-FILE ASSIGNMENT: - Tapping a tag on a file row toggles that category for that file only - Selected tags get primary-container background (#263B5E) with white text - Deselected tags stay surface-colored - The 📝 icon per row opens a per-file dropdown for fine control

CREATE NEW CATEGORY: - "➕ Create new..." tag in the tag cloud opens a text input + Create button - Created category is immediately available in the tag cloud - Categories persist via a DocumentRepository.getCategories() call - No server — categories are local to the vault metadata

IMPLEMENTATION NOTES: - File list state managed by a DocumentAddCubit (new, planned) State: { List files, Map> categoryAssignments } - Category tags built from a ValueNotifier> of all used categories - "Select All" toggles a Set selectedFiles in the cubit - Navigation: this is a full-screen route, not a modal onPressed "Continue" → getIt().navigateTo('/add-documents/review')
