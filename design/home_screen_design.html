STORAGE SECTION EXPLANATION: The "Storage" card is NOT analytics — it is a live summary of what's currently in the vault. Since the document storage layer is NOT yet implemented (see DEVELOPER_GUIDE.md §14 — "Document storage" is unchecked), this data would be computed at runtime from: - DocumentRepository.countDocuments() → "24 Documents stored" - DocumentRepository.totalSizeBytes() → "12.4 MB total" - DocumentRepository.categoryCount() → "8 Categories" - DocumentRepository.largeFileCount(threshold: 5MB) → "3 Large files" - Quota: maxVaultSizeBytes (future constant) When implemented, these would be ValueListenableBuilders or a Cubit that the HomeScreen subscribes to. Currently they are static placeholders.

DOCUMENTS SECTION: - "All" tab: lists every document in the vault (future: from DB query) - "Recent" tab: filters to documents accessed or added within 24h Logic: WHERE lastAccessedAt >= (now - 24h) OR createdAt >= (now - 24h) - "Documents" tab: filters by file-type (PDF, DOCX, etc.) - "Images" tab: filters by file-type (JPG, PNG, GIF, etc.) - Each row is tappable → opens DocumentViewerScreen (future) - Empty state: "No documents yet" with folder icon
